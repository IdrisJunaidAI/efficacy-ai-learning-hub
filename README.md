## Research and QA operating principles

**Provenance:** Document the source and permissible reuse of each dataset.

**Preprocessing:** Preserve meaningful terms, identifiers, quantities and symbols where domain context requires them.

**Validation:** Use held out evaluation, interpret per class errors and avoid training data leakage.

**Reproducibility:** Record tools, package versions, seeds, preprocessing and execution order.

**Governance:** Keep confidential and personal data out of public repositories. Distinguish synthetic demonstration data from authentic historical corpora.

**Human oversight:** Treat machine generated language signals as decision support until separately validated for the actual intended use.

The [reproducibility guide](https://github.com/IdrisJunaidAI/ITAI2373_NewsBot_Midterm/blob/main/docs/REPRODUCIBILITY.md) and [research integrity statement](https://github.com/IdrisJunaidAI/ITAI2373_NewsBot_Midterm/blob/main/docs/RESEARCH_INTEGRITY.md) explain these practices in more detail.
